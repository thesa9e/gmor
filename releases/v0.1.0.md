# GMOR v0.1.0 — Initial Public Release

This is the first citable public snapshot of the Generative Model of Reality
(GMOR) repository.

The release establishes the initial public corpus of versioned model artifacts:

- the Reality Unfolding Diagram in English and Russian (`v0.1.0`);
- the official authorial reading frame for human readers in English and Russian
  (`v0.1.1`);
- the official authorial interpretation frame for generative models in English
  and Russian (`v0.1.1`);
- the repository's artifact index, license, contribution guidelines, and
  supporting documentation.

GMOR is an original working model. This release does not present it as an
established scientific theory. The repository records stable artifacts and
their version history; the current account, interpretation, and contextual
materials are maintained on the project websites.
