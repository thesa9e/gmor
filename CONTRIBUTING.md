# Contributing

**English** | [Русский](CONTRIBUTING.ru.md)

This repository welcomes questions, corrections, and proposals. The Generative
Model of Reality remains an original model under the author's direction unless
its status is explicitly changed.

## Useful contributions

- corrections of typographical errors and factual inconsistencies;
- questions about specific formulations;
- suggestions that make the text clearer;
- identification of internal contradictions;
- proposals for organizing published materials;
- new connections between elements already present in the model;
- counterexamples to the proposed principles of reality's unfolding and folding.

## What does not automatically constitute a contribution to the model

- a personal interpretation offered as a replacement for the author's version;
- a religious, esoteric, scientific, or philosophical term treated as proof;
- correspondence with another framework treated as automatic confirmation;
- a claim that does not distinguish hypothesis from established knowledge.

## Pull requests

A pull request is treated as a proposal for the official version of the project.
By submitting one, you acknowledge that the author may accept, reject, edit, or
draw on the proposed idea in developing the project.

Please indicate:

- which file or element of the model is affected;
- what problem the change addresses;
- which published materials support it;
- whether it changes the boundaries of the model's claims.

Forks and external editions are not official versions of the model unless the
author explicitly confirms otherwise.
